# Mathématiques Numériques - Laboratoires MATLAB

Ce dépôt contient les implémentations MATLAB développées dans le cadre du cours de **Mathématiques Numériques**. Il regroupe des algorithmes fondamentaux pour la résolution de problèmes mathématiques par le calcul numérique.

## 📌 Contenu du Repository

Le code est organisé selon les thématiques clés du cours :

### 1. Intégration Numérique
*   `Integrale_Simpson.m` : Implémentation de la méthode de Simpson.
*   `Integrale_somme_de_rieman.m` : Calcul d'intégrales par les sommes de Riemann.

### 2. Équations Non-Linéaires (Zéros de fonctions)
*   `Newton_raphson_prepa_exam.m` : Méthode de Newton-Raphson pour la recherche de racines.
*   `dichotomie_prepa_exam.m` : Algorithme de dichotomie (bissection).

### 3. Équations Différentielles (EDO)
*   `RK2.m` & `RK4.m` : Méthodes de Runge-Kutta d'ordre 2 et 4.
*   `euler_cos_x_log_x_exp_x.fig` : Visualisation des résultats via la méthode d'Euler.
*   `RLC.m` : Modélisation d'un circuit électrique RLC.

### 4. Dérivation Numérique
*   `derive_premiere_ordre_1.m` & `derive_premiere_ordre_2.m` : Calcul de la dérivée première.
*   `derive_seconde_ordre_1.m` & `derive_seconde_ordre_2.m` : Calcul de la dérivée seconde.

### 5. Algèbre Linéaire
*   `gauss_jordan_1.m` : Résolution de systèmes linéaires par la méthode de Gauss-Jordan.

### 6. Divers & Fonctions Spéciales
*   `fonction_gamma.m` : Calcul ou manipulation de la fonction Gamma.
*   `ex_kinder_surprise.m` : Exercice d'application spécifique.
*   `Firstlaboratoire.m` : Scripts d'introduction et de prise en main.

### 7. Algèbre Linéaire (Suite)
*   `gauss_jordan_1.m`, `gauss_jordan_2.m`, `gauss_jordan.m` : Différentes versions de la méthode de Gauss-Jordan pour la résolution de systèmes.

### 8. Intégration Numérique (Suite)
*   `integrale_methode_trapeze.m` : Calcul d'intégrales via la méthode des trapèzes.
*   `integration_moodle.m` : Exercices d'intégration issus de la plateforme Moodle.
*   `intersection_integrale.m` : Calcul d'aires ou d'intersections via l'intégration.

### 9. Séries de Taylor & Équations Différentielles
*   `taylor_equad_diff.m` : Résolution d'équations différentielles par les séries de Taylor.
*   `taylor_equa_diff_y_et_y_prime.m` : Approche spécifique utilisant $y$ et $y'$.
*   `euler_cos_x_log_x_exp_x.fig` : Graphique résultant d'une résolution par la méthode d'Euler.

### 10. Divers
*   `ex_kinder_supprise.m` : Exercice pratique thématique.
*   `fonction_gamma.m` : Implémentation de la fonction Gamma.
*   `untitled.m` : Script de brouillon / tests temporaires.

## 🚀 Utilisation
1.  Clonez ce dépôt ou téléchargez les fichiers `.m`.
2.  Lancez **MATLAB** et naviguez jusqu'au dossier du projet.
3.  Exécutez les scripts pour tester les algorithmes sur vos propres fonctions.
